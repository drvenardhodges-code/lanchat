# Lanchat — delivery outcomes

- [x] **Firebase email/password accounts** — Users can create an account and sign in with an email address and password. Include password reset. Do not require phone OTP, real SMS, a paid billing account, or a Firebase plan upgrade during development; keep Firebase email/password authentication ready for future phone-OTP account linking.
- [x] **Optional phone profile information and phone-based discovery** — Let users provide or edit a phone number as profile information, including fictional/test numbers. The number is not verified and does not trigger SMS. Users can use a saved country-code phone number to find another account. Preserve legacy verified-phone lookup entries without making phone verification a current sign-in requirement.
- [x] **Real-time chats and conversation list** — Implement real-time one-to-one messaging powered by Firebase. Show each conversation’s latest message and recent activity. Include sent and received message bubbles with timestamps. Messages and conversation summaries are written together in one Firestore batch.
- [x] **Editable user profile** — Let users edit their name, about text, phone profile information, and profile picture. Profile text is stored in Firestore and profile images use Firebase Storage.
- [x] **Lanchat branding and responsive interface** — Name the app Lanchat. Use a light-blue color scheme and a responsive WhatsApp-inspired chat interface.
- [x] **Existing Firebase project and free-plan constraints** — Keep the existing Firebase project `lanchat-ccf2a`; do not change its billing plan or require a paid billing account. Preserve existing chats, user profiles, and other features.
- [x] **Firebase setup and integration handoff** — Document email/password provider setup, current Spark-friendly development flow, optional unverified phone profile behavior, and future phone OTP/testing-number notes. The supplied Firebase web app and Analytics settings remain connected; enable required Firebase services and deploy the included rules/indexes for live use.
